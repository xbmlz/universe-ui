## 一套围绕设计规范构建的组件

Universe UI 把飞书 Universe Design 的按钮、输入、导航和反馈组件实现为 Vue 3 SFC。组件的尺寸、间距、颜色和状态都从 `design/` 中的规范与设计图出发，而不是从其他组件库的主题出发。

## 文档结构

- **指南**：安装、接入和开发约定。
- **组件**：每个组件的 API、状态和使用方式。示例会直接读取仓库中的 Vue 源码，并在页面中渲染同一份组件。
- **设计规范**：颜色、字体、布局以及各组件的原始设计说明。

## 当前范围

第一批文档从 Button 开始。后续按设计规范逐个补充组件页面，每个页面都包含实时示例、源码和 API。
