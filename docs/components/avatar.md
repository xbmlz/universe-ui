# Avatar 头像

使用圆形或矩形头像代表用户或事物，帮助快速识别。内容支持图片、默认图标或字符。

## 使用规则

- 头像常用于展示用户形象；通过合适的尺寸与内容，帮助清晰、快速识别。
- 样式分圆形与矩形；类型分人物、群组、应用、企业 / 部门。
- 提供基本尺寸；不够用时可按 **4N** 规则调整，建议最小不低于 **20×20**，同一页头像尺寸建议不超过 3 种。

## 组成要素

1. **图像**：用户上传的人像、产品标识等
2. **图标**：尚未上传时的默认图标，部分可自定义颜色
3. **容器背景**：默认头像背景色
4. **文字**：群组自定义文字，或用户未上传时的默认文字
5. **占位**：加载中用 N300 底；整页未加载时用骨架屏（见 Skeleton）

## 控件类型

头像分圆形（人物 / 群组）与矩形（应用 / 企业 / 部门）。`kind` 决定默认形状：`person` / `group` 为圆，`app` / `enterprise` 为方；也可用 `shape` 覆盖。

### 尺寸

规范给出人物场景的典型尺寸：**20**（人员标签，与文字间距 4px）、**24**（导航 / 单行表格，间距 8px）、**32**（双行表格 / 下拉 / 消息列表，间距 12px）。也可按 4N 放大缩小。

:::demo avatar/sizes 基本尺寸
:::

### 个人头像

人物默认头像提供 4 种有语义的颜色（蓝 / 紫 / 青 / 橙），自定义场景可自选。实现里这四种是竖向渐变，其它 `color` 回落为纯色底。

:::demo avatar/person 四种人物色
:::

**取字规则：**

- 中文：取姓名后两个字，如「林七七」→「七七」
- 英文：取名和姓的首字母，如「John Smith」→「JS」
- 日文：取姓氏第一个字（需 `name-locale="ja"`），如「工藤新一」→「工」

悬停显示完整 `name`（内置 Tooltip）。

:::demo avatar/text 中 / 英 / 日取字
:::

### 图片与默认图标

有 `src` 时优先显示图片；加载失败回退到文字或默认图标。无 `name` / `text` 时按类型显示默认填充图标（安全区约为头像边长的 1/2）。

:::demo avatar/image 图片与失败回退
:::

:::demo avatar/icon 默认图标
:::

加载中背景为 N300（`--ud-color-border-card`），图片透明叠在上面直到加载完成。

### 群组头像

群组提供 8 种颜色；白底 + 色描边 + 色字。`text` 可自定义：宽字符计 2 单位，每行最多 4 单位、最多两行。

:::demo avatar/group 群组色与多行文字
:::

### 矩形头像（应用 / 企业）

应用、企业默认方形。应用取名称前两字（中文）或前两字母（英文），带 1px N900*10% 内描边；企业取首字 / 首字母。默认背景为品牌色。

:::demo avatar/square 应用与企业
:::

人物与部门混排时，规范要求应用 / 产品头像改用圆形——此时设 `shape="circle"`。

## 头像组

### 重叠排列

`AvatarGroup` 把子头像叠排：后一个压在前一个上，外描边 **2px**（与背景色一致）。建议最多展示 5 个，超出显示 `+N`；32px 时超过 999、20/24px 时超过 99 显示省略图标。悬停人物显示姓名；悬停 / 点击 `+N` 背景为 N300；**点击 `+N`** 展开剩余人员列表（头像 + 姓名）。仍抛出 `more` 事件；也可用 `more` 插槽自定义列表。

:::demo avatar/overlap 重叠与 +N
:::

### 间隔排列

不重叠时不要包 `AvatarGroup`，用间距排开即可（间距遵循 4N）。建议最多展示约 6 个。

:::demo avatar/spaced 间隔排列
:::

## 与徽标组合

右上角数字 / 状态、右下角协同圆点用 [Badge](/components/badge)。圆形头像加 `round`，协同徽标用 `placement="bottom-right"`、`tone`、`ring`。

:::demo avatar/badge 右上角与右下角徽标
:::

> 外部企业匿名场景的五种插画头像尚未入库，暂未提供对应 `kind` / 资源。

## API

### Avatar Attributes

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `src` | 图片地址；失败时回退文字或图标 | `string` | - |
| `name` | 姓名 / 名称；用于取字、无障碍标签与悬停提示 | `string` | `''` |
| `text` | 直接指定头像内文字，跳过取字 | `string` | - |
| `kind` | 头像类型 | `person \| group \| app \| enterprise` | `person` |
| `shape` | 形状；不传时随 `kind` | `circle \| square` | - |
| `size` | 边长（px）；在组内可继承 `AvatarGroup` | `number` | `32`（或组尺寸） |
| `color` | 背景色板 | `blue \| purple \| turquoise \| green \| lime \| yellow \| orange \| carmine` | `blue` |
| `nameLocale` | 人物取字脚本；`ja` 强制日文姓氏规则 | `auto \| zh \| en \| ja` | `auto` |

### Avatar Slots

| 名称 | 说明 |
| --- | --- |
| `icon` | 自定义默认图标（无图片且无文字时） |

### AvatarGroup Attributes

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `size` | 组内头像边长（px） | `number` | `32` |
| `max` | 最多展示个数；总数 ≤ `max + 1` 时全部展示，否则截断并显示 `+N` | `number` | `5` |

### AvatarGroup Events

| 事件 | 说明 | 参数 |
| --- | --- | --- |
| `more` | 点击 `+N` | `(event: MouseEvent)` |

### AvatarGroup Slots

| 名称 | 说明 |
| --- | --- |
| `default` | 子级 `Avatar` |
| `more` | 自定义剩余人员列表；作用域参数 `people`、`rest` |
