# Rate 评分

Rate 用于展示评分，或为用户提供评分功能。已打分与未打分的图标需要有明显区分，用户也可以为当前评分补充一句解释。

## 使用规则

- 默认分数段为 5，符合大多数用户对评分系统的认知，也方便在有限精度下快速评分；非特殊情况不建议修改分数段。
- 需要精确打分时使用星级评分，并可在用户作出选择后提供进一步的选项。
- 只需要「好 / 差」这类无精度的快捷反馈时，使用好评差评，而不是把星级降到两颗。

## 组成要素

1. **分数 - 已打分**：已确认或已达到的分数，悬停预览时同样按已打分渲染。
2. **分数 - 未打分**：未打分或不足的分数。
3. **即时提示（可选）**：解释当前评分状态，文案可自定义。

尺寸与颜色取自 `rate.md` 的设计说明与标注图：

| 项 | 值 |
| --- | --- |
| 单个星星容器 | 32 × 32 px |
| 星星图标 | 28 × 28 px，悬停放大至 32 × 32 px |
| 容器间隔 | 16 px |
| 星星与提示文案的间距 | 12 px |
| 未打分颜色 | N300（配图取样 #D7D9DB） |
| 打分 / 悬停颜色 | Y500（配图取样 #FFC60A） |
| 提示文案 | 14 px，`--ud-color-text-secondary` |

提示文案位于星星**下方居中**，不是右侧。`N300` 不在现有色阶里，已按配图取样值补成 `--ud-color-border-muted`（#D7D9DB），Slider 滑轨复用同一个 token。

## 步长

可交互的评分组件默认步长为 1。也可以开启 0.5 步长，用于不同精度的打分系统：点击星星右半边给全星，点击左半边给半星。

:::demo rate/half 步长 1 与步长 0.5
:::

仅用于展示时，评分可以是很精确的小数，此时组件只渲染、不接收交互：

:::demo rate/display 展示小数
:::

## 即时提示

为了统一评分标准，悬停时需要即时显示当前分数的提示文字，选中后提示文字依然保留。默认文案为「很差 / 较差 / 一般 / 较好 / 很好」，可通过 `texts` 替换。

- 未评分时显示 `emptyText`，默认「点击评分」。
- 半星的提示与下一档全星一致：2.5 分显示 3 分的文案。
- 文案超长时折行，保证完整显示，同时文案本身应尽量精简。

:::demo rate/texts 默认文案、半星与自定义文案
:::

## 清除评分

点击即选择评分，再次点击其他位置即改变评分。是否允许清除由场景决定：允许清除时，再次点击当前分数会回到未选择状态；禁止清除时，再次点击同一位置没有变化。

:::demo rate/clearable 可清除与禁止清除
:::

## 自定义图标与颜色

默认形状为星星，也可以用 `icon` 换成其他图标，或覆盖 `--ud-rate-active` 换一种颜色标记分数。

:::demo rate/custom 自定义图标与颜色
:::

## 状态

| 状态 | 表现 |
| --- | --- |
| Normal | 未打分 N300，已打分 Y500，图标 28px |
| Hover / Pressed | 当前图标放大到 32px，并按悬停位置预览分数；0.5 步长时按左右半边区分 |
| Selected | 已打分保持 Y500，图标回到 28px |
| Disabled | 未打分图标变浅，不可交互，提示文案保留 |
| Readonly | 与 Disabled 同色，仅阻止交互，用于纯展示 |

`rate.md` 只给出了 Normal、Hover / Pressed 与 Selected 三种状态，Disabled 与 Readonly 是补全项，配色沿用禁用文字色。

:::demo rate/states 选中、禁用与只读
:::

## 好评差评

`rate.md` 把「好评差评」列为评分的另一种控件类型（普通与小型两种规格，最小宽度 112px，选中后为浅色填充按钮）。`packages/vue` 目前只实现了星级评分，好评差评尚未实现，详见 `TODO.md`。

## API

### Rate Attributes

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `v-model` | 当前分数，`0` 表示未评分 | `number` | `0` |
| `count` | 分数段，即星星数量 | `number` | `5` |
| `allowHalf` | 是否允许半星，点击左右半边分别给半星与全星 | `boolean` | `false` |
| `clearable` | 再次点击当前分数是否清除 | `boolean` | `true` |
| `showText` | 是否显示即时提示 | `boolean` | `false` |
| `texts` | 各分数段的提示文案，索引 0 对应 1 分 | `string[]` | 很差 / 较差 / 一般 / 较好 / 很好 |
| `emptyText` | 未评分时的提示文案 | `string` | `点击评分` |
| `icon` | 自定义图标组件 | `Component` | 星形 |
| `disabled` | 是否禁用 | `boolean` | `false` |
| `readonly` | 是否只读 | `boolean` | `false` |
| `label` | 评分组的 `aria-label` | `string` | `评分` |

### 键盘操作

| 按键 | 说明 |
| --- | --- |
| `Tab` | 在各颗星之间移动焦点 |
| `Enter` / `Space` | 选中当前焦点所在的整颗星；已选中且 `clearable` 时清除 |

### 样式变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `--ud-rate-active` | 已打分与悬停的颜色 | `--ud-yellow-500` |
| `--ud-rate-idle` | 未打分的颜色 | `--ud-color-border` |
