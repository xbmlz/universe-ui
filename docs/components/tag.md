# Tag 标签

Tag 有四种形态：`property` 用于分类和属性，`option` 用于可筛选或可移除的选项，`status` 用于流程状态，`avatar` 用于带身份头像的成员标签。

## 组件类型

### 类型总览

| 类型 | 说明 |
| --- | --- |
| 属性标签 | 描述事物、提供辅助信息 |
| 选项标签 | 表示事物本身，可筛选或移除 |
| 状态标签 | 展示进度或发展状态 |
| 头像标签 | 展示人员、组织等身份 |

### 属性标签

#### 使用方式

属性标签用于描述事物、提供辅助信息；标签会增加视觉噪音，应克制使用，可单个或成组出现。

#### 注意事项

标签中的图标、文字和关闭按钮都是可选配项；不可仅配置关闭按钮。

#### 颜色配置

默认根据色板提供 12 种标签配色，颜色含义按业务需求定义。

:::demo tag/basic 属性标签颜色
:::

#### 透明度配置

默认使用带透明度的底色；背景为非常规界面时使用不透明实心底色。

:::demo tag/property 透明与实心底色
:::

#### 标签状态

`disabled` 禁止交互；`solid` 对属性标签和状态标签生效。

#### 使用示例

属性标签用于描述部门性质等属性；标签代表物件本身时应使用选项标签。

#### 位置说明

标签与左右相邻元素保持 8px 间距；多行标签行间距 8px。

### 选项标签

#### 使用方式

选项标签用于表示事物本身，颜色对比度较高、饱和度较低；不建议在系统层面建立警示等语义。

:::demo tag/option 可移除与禁用
:::

#### 样式配置

提供 `xs`、`sm`、`md`、`lg` 四种尺寸；图标、文字和关闭按钮均为可选配项。

:::demo tag/size 四种尺寸
:::

#### 状态说明

支持普通、hover、点击和禁用状态；带移除操作的标签有两个热区。

#### 颜色配置

默认根据色板提供 12 种标签配色。

:::demo tag/option-color 选项标签颜色
:::

#### 标签状态

`disabled` 禁止移除并保留禁用样式。

#### 使用示例

选项标签用于表示物件本身；避免与属性标签混合表达同一含义。

#### 位置说明

水平相邻元素间距 8px；标签多行展示时行间距 8px。

### 状态标签

#### 使用场景

用于展示事件的进度或发展状态，常见于列表、详情、流程和表单。

:::demo tag/status 状态标签
:::

#### 颜色配置

蓝色表示进行中，绿色表示成功或已完成，红色表示失败或错误，橙色表示待处理，灰色表示负向或未开始。

#### 缺省规则

尽可能保持内容完整；展示空间有限时按实际场景省略。

#### 文本说明

状态文案应简洁、明确，避免歧义和过度解释。

#### 位置说明

按所在组件规范对齐，避免遮挡关键信息。

### 头像标签

#### 使用场景

用于展示人员姓名、照片、组织等身份，常见于表单和选择器。

:::demo tag/avatar 普通头像标签与带移除操作的头像标签
:::

#### 尺寸说明

支持 `xs`、`sm`、`md`、`lg`，头像尺寸随标签尺寸缩放。头像标签是两端半圆的**胶囊形**（全圆角 `--ud-radius-full`），圆形头像嵌在左端半圆内；属性、状态、选项三类标签则是 `Radius-XS` 的小圆角矩形，不要混用。

:::demo tag/avatar-size 四种尺寸与移除
:::

#### 状态说明

头像标签分为「普通头像标签」和「带移除操作的头像标签」两类。普通标签只有标签主体一个热区；带移除操作的标签有标签主体和 × 移除按钮两个热区，各自有悬浮态与点击态，另有禁用态。上方示例把 `Normal / Hover / Pressed / Disabled` 四态和 `Hover icon / Press icon` 两个图标热区固定呈现，便于与设计稿对照；实际使用时由鼠标交互触发，`disabled` 会禁止移除。

#### 颜色配置

建议使用灰色或浅蓝色；非照片头像的图标颜色应与底色对应。

#### 缺省规则

仅用于描述姓名，单行展示，尽量保持内容完整；空间有限时省略。

:::demo tag/avatar-ellipsis 平铺展示与省略折叠
:::

#### 位置说明

与左右相邻元素保持 8px 间距；多行标签行间距 8px。

#### 使用示例

用「-」表达层级关系，用「（）」表达说明关系；避免使用错误符号分割或在 Tag 中嵌套 Tag。

## API

### Tag Attributes

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `variant` | 标签形态 | `property \| option \| status \| avatar` | `property` |
| `size` | 尺寸 | `xs \| sm \| md \| lg` | `md` |
| `color` | 颜色 | `neutral \| blue \| turquoise \| green \| lime \| yellow \| orange \| red \| carmine \| indigo \| purple \| cyan` | `neutral` |
| `solid` | 是否使用实心填充 | `boolean` | `false` |
| `closable` | 是否显示移除按钮 | `boolean` | `false` |
| `disabled` | 是否禁用 | `boolean` | `false` |
| `status` | `status` 形态的语义状态 | `pending \| success \| failure \| awaiting \| negative` | `pending` |
| `marker` | `status` 形态的标记样式 | `dot \| icon \| none` | `dot` |
| `statusIcon` | 自定义状态图标 | `Component` | - |
| `icon` | 标签图标 | `Component` | - |
| `label` | 标签文案，默认插槽优先 | `string` | `''` |
| `avatarName` | 头像名称 | `string` | `''` |
| `avatarSrc` | 头像图片地址 | `string` | - |
| `avatarKind` | 头像类型 | `person \| group \| app \| enterprise` | `person` |
| `avatarColor` | 头像底色 | `AvatarColor` | `blue` |
| `twoTone` | 是否使用双色背景 | `boolean` | `false` |

### Tag Events

| 事件 | 说明 | 参数 |
| --- | --- | --- |
| `close` | 点击移除按钮 | `MouseEvent` |

### Tag Slots

| 名称 | 说明 |
| --- | --- |
| `default` | 标签文案 |
| `icon` | 自定义图标 |
| `status-icon` | 自定义状态标记 |
