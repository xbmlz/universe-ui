# Breadcrumb 面包屑

显示当前页面在系统层级结构中的位置，并能向上返回。系统超过两级、需要告知当前位置或提供向上导航时使用。也可用于穿梭框等容器内的路径导航。

## 组成要素

1. **文本**：层级页面名称
2. **省略符**：路径超长时隐藏中间层级
3. **分割符**：表达层级嵌套（图标 **16px**，与文本间距 **4px**）
4. **背景**：承载被隐藏层级的悬浮托盘（与主条间距 **8px**，左右内边距 **12px**）

## 基础用法

末级为当前页，不可点；前序项可带 `href`，或只监听 `select`。

## 超长折叠

路径超出容器宽度时自动折叠：从**第二层级起**隐藏，直至放得下；极端情况优先保留第一级与最后一级。悬停「…」展示被折叠路径；托盘内仍超长时可折行。

页面场景建议面包屑约占正文宽度一半；选人 / 穿梭等场景则跟容器同宽。

:::demo breadcrumb/overflow 窄容器下折叠
:::

## 单层级超长

单个层级文本最大约 **162px**（约 10 个中文字符），超出省略；悬停气泡展示完整文案。

:::

## API

### Breadcrumb Attributes

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `items` | 面包屑层级 | `BreadcrumbItem[]` | - |

### Breadcrumb Events

| 事件 | 说明 | 参数 |
| --- | --- | --- |
| `select` | 点击某一层级（含托盘内） | `(index: number)` |

### BreadcrumbItem

| 字段 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `label` | 层级文案 | `string` | - |
| `href` | 可选链接；不传时渲染为按钮，仍触发 `select` | `string` | - |
