# Pagination 分页

分页用于将内容分为多个页面，可快速定位或切换页码浏览内容。列表很长、滚动不便，或一次加载全部数据成本过高时使用；不适合分页时，优先考虑懒加载。

## 组成要素

1. **数据总量**：显示数据总条数
2. **翻页**：上一页 / 下一页
3. **页码区**：当前页高亮，点击切换
4. **每页条数**：常见 10 / 20 / 50 / 100 条/页，可按场景配置
5. **快速跳转（可选）**：输入页码后回车跳转

## 控件类型

分 **普通分页** 与 **小型分页**。普通用于页面级（如表格右下方，与表格右对齐）；小型用于弹窗、卡片等轻量区域。

### 普通分页

翻页与页码最小 **28×28**，页码左右内边距 **4px**；图标 **16×16**。默认展示总量、每页条数与跳转。

:::demo pagination/basic 总量、页码、每页条数与跳转
:::

只有 1 页时仍显示页码，跳转区禁用。

:::demo pagination/single 仅一页
:::

### 小型分页

翻页与页码最小 **24×24**，页码左右内边距 **2px**，页码间距 **4px**。默认不展示总量、每页条数与跳转；需要时再单独打开。

:::demo pagination/small 小型
:::

## 页码折叠

页数较多时：默认展示前 5 页 +「…」+ 最后一页。悬停「…」变为双箭头，点击跳转 **当前页 ± 5**。点到中间页时，保留首尾页，并展开当前页前后各两页。

:::demo pagination/many 多页与「…」跳转
:::

## 快速跳转

输入框遵循输入框交互：超过最大页跳到最后一页并清空；输入 `0` 跳到第 1 页；回车触发跳转；用页码区切换时清空输入。

:::demo pagination/jumper 跳转至
:::

## 禁用

整组禁用时，翻页、页码、每页条数与跳转均不可操作。

:::demo pagination/disabled 禁用
:::

## API

### Pagination Attributes

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `page` / `v-model:page` | 当前页（从 1 起） | `number` | `1` |
| `pageSize` / `v-model:page-size` | 每页条数 | `number` | `10` |
| `total` | 数据总量 | `number` | `0` |
| `pageSizes` | 每页条数候选项 | `number[]` | `[10, 20, 50, 100]` |
| `size` | 普通 / 小型 | `md \| sm` | `md` |
| `disabled` | 是否禁用 | `boolean` | `false` |
| `showTotal` | 是否显示总量；不传时 `md` 显示、`sm` 隐藏 | `boolean` | - |
| `showSizes` | 是否显示每页条数；不传时 `md` 显示、`sm` 隐藏 | `boolean` | - |
| `showJumper` | 是否显示跳转；不传时 `md` 显示、`sm` 隐藏 | `boolean` | - |
