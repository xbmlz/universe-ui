# 组件总览

组件按设计规范的分类组织：基础、数据录入、数据显示、导航和反馈。文档按页面逐个补齐，每个页面都包含实时示例、源码和手写 API 表。

## 基础

| 组件 | 说明 |
| --- | --- |
| [Icon 图标](/components/icon) | IconPark 图标与尺寸 |

## 数据录入

| 组件 | 说明 |
| --- | --- |
| [Button 按钮](/components/button) | 基础按钮、按钮组、分裂按钮、图标和尺寸 |
| [Input 输入框](/components/input) | 文本、数字、多行、验证码输入与输入组 |
| [Select 选择器](/components/select) | 单选、多选、搜索与状态 |
| [Checkbox 多选框](/components/checkbox) | 独立选项与多选框组 |
